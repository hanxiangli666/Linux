# Linux

A structured Linux learning repository covering Linux fundamentals, LFCS preparation, shell usage, and shell scripting practice.

## Purpose

This repository supports my systems foundation. It is not positioned as a product; it documents hands-on learning across Linux operations, command-line workflows, package management, boot and filesystem concepts, and shell scripting.

## Main Areas

```text
linux-basics-course/                                      Linux basics and labs
shell-scripting-for-beginners-course/                     Shell scripting practice
Linux Foundation Certified System Administrator (LFCS)/    LFCS preparation material
```

## Skills Covered

- Shell navigation and command-line help.
- Bash basics.
- Linux kernel and boot sequence.
- File types and filesystem hierarchy.
- Package management.
- User, group, permission, and process concepts.
- Shell scripting fundamentals.
- LFCS-oriented operations practice.

## Portfolio Role

This repository supports the infrastructure side of my profile. My main portfolio projects show web and AI systems; this repository shows the operating-system foundation needed to deploy, debug, and operate them.
